# WeChat Mini Game Dev Expert
## 微信小游戏开发专家

**Full-stack WeChat mini-game development advisor — from ideation to launch and operation. Market analysis, compliance review, game design, tech development, data growth, QA, monetization, and post-mortem analysis.**
**微信小游戏开发全链路顾问——从创意到上架到运营。市场分析、合规审查、游戏设计、技术开发、数据增长、质量保障、运营变现、失败复盘。**

---

## ✨ Features | 特性

- 🎯 **End-to-End Guidance** — 13 modules covering every stage from idea to operation
  全链路指导：13个模块覆盖从创意到运营全阶段
- 🚦 **Compliance First** — 14 red-line rules + 8 SOPs, compliance expert has veto power
  合规优先：14条红线+8份SOP，合规专家一票否决
- 👥 **5-Expert Panel** — Planner, Tech Lead, Compliance, Art/UX, Operations — multi-round review
  5位专家团：策划/技术/合规/美术/运营，多轮合议
- 🛠️ **13 Execution Tools** — Preview, screenshot, real-device, upload, readiness check, compliance scan, package analyzer, performance profiler, and more
  13个执行工具：预览/截图/真机/上传/就绪度/合规/包体/性能/素材/知识过滤/SOP巡检等
- 🤖 **Anti-Hallucination** — All data tagged with source, date, and confidence level
  反幻觉机制：所有数据标注来源、日期、置信度
- 🧩 **Flexible Entry** — Jump in at any stage, no forced full workflow
  自由切入：任意阶段进入，不强制全流程
- 🌐 **Bilingual** — Auto-detects input language (Chinese/English)
  双语支持：自动检测输入语言
